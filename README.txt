Перед началом работы:

1. Создать файл .env в этом каталоге, содержащий значения полей 
  baseURL - URL BPMSoft до первого /, 
  login - логин пользователя автотестов, 
  password - пароль пользователя автотестов.

2. npm install - установка зависимостей проекта;
3. npx playwright install - установка зависимостей playwright: браузеров и прочего ПО.
