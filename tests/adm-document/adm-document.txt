| Step | Action | Expected result |
| 1 | Предусловия: 1. В системе существует запись объекта "Контакт" со следующими параметрами:- [ФИО] = "Сидорова Анна Викторовна ";- [Тип] = "Сотрудник".2. В системе существует пользователь со следующими параметрами:- [Контакт] = запись предусловия 1;- Назначены следующие организационные роли: "Департамент по работе с обращениями клиентов";3. В системе существует запись объекта «Контакт» со следующими параметрами:- [ФИО] = «Иванов Иван Иванович»;- [Тип] = «Клиент»;- [AБС Id] = «1234567890». 4. В системе существует запись объекта "Продукты клиента", где:- Все обязательные поля заполнены. - [Тип] = "Дебетовая карта";- [Номер] = "0956758736509745";- [Номер счета] = "1673492747830175";- [UID карты] = "568391"; - [Клиент] = запись из предусловия 3.5. В системе существует запись объекта "Обращение" со следующими параметрами:- [Состояние] = «На рассмотрении»;- [Заявитель] != контакт из предусловия 3;- Все обязательные поля заполнены. ||
| 2 | Авторизоваться в системе под пользователем из предусловия 2. | Авторизация прошла успешно. Открыта главная страница системы. В панели разделов отображен раздел «Обращения». |
| 3 | Открыть раздел "Обращения". | Открыт реестр записей раздела. Отображена запись объекта "Обращение" из предусловия 5. |
| 4 | Открыть запись объекта "Обращение" из предусловия 5. | Открыта запись объекта "Обращение" из предусловия 5, где поле [Заявитель] не заполнено.Отображена вкладка "Обработка". |
| 5 | Заполнить поле [Заявитель] = контакт из предусловия 3. | Поле заполнено.Автоматически заполнено поле [AБС Id клиента] = «1234567890». |
| 6 | Перейти на вкладку "Информация по обращению". | Вкладка "Информация по обращению" открыта. Отображена деталь "Распорядительные документы". Рядом с деталью отображена кнопка "+" (Добавить). |
| 7 | Нажать кнопку "+" (Добавить) в детали "Распорядительные документы". | Открыта страница редактирования распорядительного документа, где:В профиле страницы отображены поля:- [Номер] не заполнено;- [Статус] = "Новое";- [Тип документа] не заполнено; (обязательно для заполнения);- [Обращение] = [Номер] записи из предусловия 5 (обязательно для заполнения);- [Клиент] = контакт из предусловия 3 (обязательно для заполнения);- [АБС Id клиента] = «1234567890»;- [Создал] = контакт из предусловия 1;- [Дата создания] не заполнено;. |
| 8 | Заполнить поле [Тип документа] = "По картам (тип 1)". | Поле заполнено. |
| 9 | Заполнить поле [Продукт] = запись из предусловия 4. | Поле заполнено.Автоматически заполнены поля:- [Номер карты] = [Номер] записи из предусловия 4;- [Номер карточного счета] = [Номер счета] записи из предусловия 4; ;- [UID карты] = [UID карты] записи из предусловия 4. |
| 10 | Заполнить поле [Кейс]. | Поле заполнено.Поле [Комментарий] автоматически заполнено. |
| 11 | Нажать на кнопку "+" в детали "Типы операций". | Создана новая запись в детали "Типы операций". |
| 12 | Нажать на иконку "Лупы" в поле [Тип операции]. | Открыто модальное окно с записями и кнопками "Выбрать", "Поиск" и "Отмена". |
| 13 | Встать на любую запись и нажать на кнопку "Выбрать". | Модальное окно закрыто.Отображена деталь "Типы операций" с запись, выбранной на текущем шаге. |
| 14 | Нажать на кнопку "Сохранить" на странице распорядительного документа. | Страница распорядительного документа сохранена. |
| 15 | Закрыть страницу распорядительного документа. | Страница распорядительного документа закрыта.Открыта страница обращения, где на детали "Распорядительные документы" отображена запись:- [Номер] не заполнено;- [Тип распоряжение] = "По картам (Тип 1)";- [Кейс] заполнено;- [Статус] = "Новое";- [Дата создания] заполнено. |
